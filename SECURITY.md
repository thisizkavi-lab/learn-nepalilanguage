# Security Policy

Learn Nepali is a static learning site, but security reports are still welcome.

## Supported Version

The `main` branch and the live GitHub Pages deployment are the supported versions.

## Reporting a Vulnerability

If you find a vulnerability, please open a GitHub issue only if the details are safe to share publicly. For sensitive reports, contact the maintainer privately through the GitHub profile associated with this repository.

Helpful reports include:

- A clear description of the issue.
- Steps to reproduce.
- Affected browser or environment.
- Any suggested fix, if you have one.

Please avoid testing that could disrupt the live site or other users.
