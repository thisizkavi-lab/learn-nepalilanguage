# Code of Conduct

Learn Nepali is built to help people learn and improve together. Please keep discussions respectful, specific, and welcoming to speakers and learners at different levels.

## Expected Behavior

- Be kind and constructive.
- Respect regional, dialect, and formality differences in Nepali.
- Explain corrections with context when possible.
- Assume good intent when someone makes a language mistake.
- Keep feedback focused on the project and the learning experience.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discrimination based on language background, nationality, ethnicity, gender, religion, disability, age, or identity.
- Dismissing contributors for being beginners or non-native speakers.
- Spam, unrelated promotion, or abusive behavior.

## Enforcement

Project maintainers may edit, hide, or remove comments and contributions that violate this code of conduct. Repeated or severe violations may result in being blocked from participating in the repository.

If you see a problem, open a private maintainer contact path if available, or file an issue with only the necessary details.
