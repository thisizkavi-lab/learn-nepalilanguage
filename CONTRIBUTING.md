# Contributing to Learn Nepali

Thanks for helping make Nepali easier to learn. This project is most useful when speakers, learners, teachers, and designers all help catch small mistakes and add real-world examples.

## Good First Contributions

- Correct a translation, romanization, or phrase that sounds unnatural.
- Add a missing everyday word, phrase, or short dialogue.
- Suggest a better explanation for a Devanagari character or grammar note.
- Record or propose clearer pronunciation/audio examples.
- Improve accessibility, mobile layout, or quiz behavior.
- Report a confusing learning flow with a screenshot or short note.

## Content Guidelines

- Prefer spoken, everyday Nepali over overly formal textbook language.
- Include Devanagari, romanization, and English meaning when adding vocabulary.
- Add context where it matters: formality, region, common alternatives, or when a phrase sounds odd.
- Keep examples friendly, practical, and useful for beginners.
- If you are unsure, open an issue first and explain the uncertainty.

## Development Setup

```bash
git clone https://github.com/thisizkavi-lab/learn-nepalilanguage.git
cd learn-nepalilanguage
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

Before opening a pull request, run:

```bash
npm run build
npm run lint
```

## Pull Requests

- Keep pull requests focused on one content area or feature.
- Explain what changed and why it helps learners.
- For content changes, mention whether you are a native/fluent speaker, learner, or citing another source.
- For UI changes, include before/after screenshots when practical.

## Reporting Issues

Use the issue templates for language corrections, bugs, and feature ideas. Small reports are welcome; even "this phrase sounds unnatural" is useful.
